# Portfolio-Profissional
Meu Perfil Profissional - Maria Fernanda Ferreira de Araújo

Descrição: Portfólio profissional que apresenta minha formação, contatos, projetos e objetivos.
Funcionamento: O projetos possui uma navbar superior que direciona para cada parte da página, um carrosel com uma breve introdução de cada seção e botões que direcionam para minha página no Github.
Recurso novo: Carrosel de imagens, animações de transição no carrosel, hover nos botões que mudam sua cor. Os recursos foram implementados através dos sites do Bootstrap e W3schools, com consulta para dúvidas na inteligência artificial Claude.
